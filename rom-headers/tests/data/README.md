# Test data

The ROMs here come from [rom-tools](https://github.com/sargunv/rom-tools)' test
data, which takes them from:

- [XboxDev/cromwell](https://github.com/XboxDev/cromwell)
  ([LGPL-2.1](https://github.com/XboxDev/cromwell/blob/86f547387184d1001d377cce97d3756c8acf91cc/COPYING)):
  `default.xbe`, Xromwell's executable.
- [Zophar's Domain PD ROMs](https://www.zophar.net/pdroms/) (public domain): the
  rest.

They're used only as sample data for the tests.
